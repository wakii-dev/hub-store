đi trọn luồng user thật (login→navigate→action→logout) cho 5 roles, và session-handling
(logout/401-refresh-fail) không có spec nào phủ.

không phải trải nghiệm người dùng; Admin + WarehouseEmployee + logout + 401-redirect chưa
từng walkthrough.
### Expected outcome
Auth + matrix đúng ở cả 3 tầng (DOM/VISUAL/FLOW) cho 5 roles; regression spec 10xx guard
lại domain; 0 bug P0–P2 mở.
