3. **PDF preview**: react-pdf THEO SPIKE 2 verdict (SF-1) — gọi `POST /fulfillment/print` (printType hiện tại + batchCode) → PDF bytes (application/pdf từ print-service qua BFF) → render blob; **zoom slider**.

5. **In**: POST print với printerId → job feedback (thành công/thất bại — AntD message).
6. **"In tất cả"**: 5 calls TUẦN TỰ (1 call/PDF — pin §3.7, KHÔNG có endpoint printAll) + progress hiển thị.
7. i18n keys `fulfillment.*` (VI + EN). Unit tests (mock api-client): tabs switching, print call payload, print-all tuần tự.
