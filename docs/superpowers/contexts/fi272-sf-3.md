## Spec slice (SF-3 chịu trách nhiệm)

1. **Keycloak Deployment** — image pin cụ thể (quay.io/keycloak/keycloak:<tag> — chọn tag ổn định
   hiện hành, ghi lý do), `start-dev --import-realm`:
   - `KC_HEALTH_ENABLED=true` + management port 9000 → liveness/readiness probe target
     `/health`, `/health/ready` trên :9000 (Keycloak boot chậm → startupProbe với
     failureThreshold rộng).
   - `KC_HTTP_RELATIVE_PATH=/keycloak` — **contract với SF-4**: ingress route `/keycloak` sẽ trỏ
     vào service này; không có env này path-prefix sẽ 404.
   - `KC_DB=postgres` + `KC_DB_URL` trỏ `postgres:5432/keycloak` (DB do SF-1 initdb tạo),
     credentials từ Secret `postgres-credentials` (SF-1); admin user/pass từ Secret
     `keycloak-admin` (SF-1).
   - resources requests/limits hợp lý cho dev (Keycloak RAM-heavy).
2. **Realm JSON minimal** (mount/`--import-realm` qua ConfigMap hoặc Secret): realm `hub-store`;
   roles `Coordinator`, `WarehouseOps`, `Manager`; ≥1 dev user mỗi role VỚI credentials ghi trong
   realm JSON (dev-only); client cho phép password grant: `directAccessGrantsEnabled: true` +
   `publicClient` cho app sau này. GHI RÕ comment dev-only.
3. **Realm import config** — mount realm JSON vào `/opt/keycloak/data/import/`.
4. **Service** ClusterIP `keycloak:8080` (+ management port nếu cần).
5. **Smoke token qua port-forward**: `kubectl port-forward` → curl password grant
   `POST /realms/hub-store/protocol/openid-connect/token` → lấy access_token (verify decode roles).
6. **Docs flag FI-245**: comment trong dir k8s/base/keycloak + 1 đoạn doc ngắn — khi FI-245
   SF-4 merge, realm JSON có thể thay bằng artifact đầy đủ của FI-245 (SF-5 sẽ ghi hướng chính
   thức trong wiring doc).

## ACCEPTANCE (user-visible)

- Pod keycloak Ready trong namespace hub-store (startup probe không flap), DB connection tới
  postgres/keycloak thành công (log không có DB error).
- `kubectl port-forward` + curl password grant → access_token chứa đúng 3 roles trong realm_access.
- Realm import idempotent: re-apply không duplicate lỗi nghiêm trọng (import realm existing =
  skip/bị ignore là hành vi Keycloak chuẩn — verify không crash-loop).
