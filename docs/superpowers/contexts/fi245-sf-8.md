## Spec slice
1. BFF endpoints (owner SF-8): list users, create user (+ roles), set password, enable/disable — gọi Keycloak Admin REST API bằng service-account client credential (env `KC_ADMIN_CLIENT_ID/SECRET` — KHÔNG hardcode; thêm vào .env.example pattern).
2. FE màn "Users" trong shell — nav item CHỈ hiện với role Manager (role matrix mở rộng; route guard như screens khác).
3. Chức năng màn: bảng users (username, enabled, roles), tạo user (form: username + password + chọn role Coordinator/WarehouseOps/Manager), toggle khóa/mở, set password lại.
4. Màn mới KHÔNG được đổi testid/DOM của screens cũ (E2E cũ xanh); thêm e2e spec mới cho users flow.
5. UI theo design direction nếu `docs/superpowers/designs/sf6-direction.md` đã tồn tại tại thời điểm code; chưa có → antd4 sạch, SF-11 hội tụ sau.

## ACCEPTANCE (user-visible)
- Login Manager → thấy nav "Users" → list đúng users Keycloak (3 users mẫu).
- Tạo user mới role WarehouseOps → logout → login user mới OK, đúng quyền.
- Disable user → user đó không login được nữa.
- Coordinator/WarehouseOps KHÔNG thấy nav Users; gọi thẳng API → 403.
