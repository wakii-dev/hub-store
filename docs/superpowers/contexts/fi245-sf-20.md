# FI-245 SF-20 Context Pack — Đơn dịch vụ kỹ thuật FE
> Epic spec: docs/superpowers/specs/ict-service-support-postgres-prod-spec.md §3.20. Bracket: docs/superpowers/brackets/fi245-postgres-production.md. Tier 4 — deps SF-19 (API) + SF-6 (design system).

## Spec slice
1. **3 tab** trong 1 screen "Đơn dịch vụ": Giao hàng (card list: trạng thái, tài xế, người gửi/nhận, phí, SP) / Lắp đặt (KTV phụ trách, timeline, đơn giao liên quan, phí dịch vụ) / KTV-CTV (bảng NV theo ngày: số đơn giao/lắp, vùng).
2. **Filter** mặc định hôm nay; filter lưu URL + sessionStorage (reload giữ).
3. **Assign modal**: gợi ý NV (SF-19 suggest) + chọn + confirm; re-assign cùng modal.
4. **KTV-CTV detail**: per staff nhóm theo ngày — đơn giao + đơn lắp đặt.
5. **Gọi điện** `tel:` trên receiver (isShowPhoneCall flag); **buttons** render theo flag BE (không nút không flag).
6. Design system SF-6 100%; E2E spec mới; không đổi testid screens cũ.
