# FI-245 SF-15 Context Pack — NVC backend + mock carrier provider
> Epic spec: docs/superpowers/specs/ict-service-support-postgres-prod-spec.md §3.15. Bracket: docs/superpowers/brackets/fi245-postgres-production.md. Tier 3 — deps SF-3 (batches trên Postgres).

## Spec slice
1. **Carrier adapter interface** (Go, batching-service hoặc module riêng): `GetQuotes(req) / ConfirmPlanning / Book / CancelDelivery / CancelBatch / GetBookingDetail` — impl đầu tiên: `MockAhamoveAdapter`. Swap provider thật sau = adapter impl mới + env, KHÔNG đổi callers.
2. **MockAhamove provider**: service riêng trong compose (Node/Go nhẹ) — mô phỏng quotes theo tải trọng (6 mức TRUCK-ECO…, phí theo distance), booking → gán tài xế giả + licensePlate + trạng thái timeline tự chạy theo thời gian (ORDER_CREATED → DRIVER_FOUND → DELIVERING → COMPLETED, có nhánh FAILED); dữ liệu trong memory là đủ (provider giả).
3. **Endpoints** (qua BFF REST, shape khớp app gốc): `POST /delivery-batch/quotes`, `POST /delivery-batch/planning/confirm`, `POST /delivery-batch/booking` (batchCode + shipmentPlannings[] COD/totalBill/stopOrder), `POST /delivery-batch/cancel-delivery-order`, `POST /delivery-batch/cancel-batch`, `GET /delivery-batch/searchbookingdetail?planningIds=`.
4. **Batching DB V2** (golang-migrate): plannings, bookings, shipment_statuses/tracking_events, addon_services catalog, fee_limits (per-SP — shop/product? lấy theo shop cho đơn giản, ghi chú rõ).
5. **Fee-limit rules BE-authoritative**: quote trả `isExceedFeeLimit`; confirm/booking chặn khi total > limit — FE chỉ render, BE là chốt chặn.
6. Addon catalog: nhóm ROUTE/LOADING (radio), DOCUMENT (checkbox, phí 0), ROUND-TRIP; serviceApplieds filter theo xe.
