# FI-245 SF-15 Context Pack — NVC backend: Ahamove adapter dual-mode (mock default / real khi có key)
> Epic spec: docs/superpowers/specs/ict-service-support-postgres-prod-spec.md §3.15. Bracket: docs/superpowers/brackets/fi245-postgres-production.md. Tier 3 — deps SF-3 (batches trên Postgres).

## Spec slice
1. **Ahamove adapter dual-mode** (Go, batching-service): env `AHAMOVE_MODE` tự chọn — `real` khi env có `AHAMOVE_API_KEY` + `AHAMOVE_PARTNER_TOKEN` (gọi api.ahamove.com thật, auth/signing chuẩn); `mock` khi không có (MẶC ĐỊNH): trả response shape Ahamove thực tế — quotes 6 tải trọng phí theo distance, booking gán tài xế giả + licensePlate + timeline trạng thái tự chạy theo thời gian (ORDER_CREATED → DRIVER_FOUND → DELIVERING → COMPLETED, nhánh FAILED), tag `[MOCK]` trong log + response meta. Điền key + đổi mode = thật, KHÔNG sửa code. KHÔNG rải fixture/mock ngoài adapter.
2. **Endpoints** (qua BFF REST, shape khớp app gốc): `POST /delivery-batch/quotes`, `POST /delivery-batch/planning/confirm`, `POST /delivery-batch/booking` (batchCode + shipmentPlannings[] COD/totalBill/stopOrder), `POST /delivery-batch/cancel-delivery-order`, `POST /delivery-batch/cancel-batch`, `GET /delivery-batch/searchbookingdetail?planningIds=`.
3. **Batching DB V2** (golang-migrate): plannings, bookings, shipment_statuses/tracking_events, addon_services catalog, fee_limits (per-shop).
4. **Fee-limit rules BE-authoritative**: quote trả `isExceedFeeLimit`; confirm/booking chặn khi total > limit — FE chỉ render, BE là chốt chặn.
5. Addon catalog: nhóm ROUTE/LOADING (radio), DOCUMENT (checkbox, phí 0), ROUND-TRIP; filter theo xe.
6. Mock state trong-memory của adapter là đủ (provider state, không phải business data — business data vẫn Postgres thật).
