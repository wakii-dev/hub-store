# FI-245 SF-17 Context Pack — Khu vực hoạt động NV
> Epic spec: docs/superpowers/specs/ict-service-support-postgres-prod-spec.md §3.17. Bracket: docs/superpowers/brackets/fi245-postgres-production.md. Tier 3 — deps SF-2 (Postgres + Flyway pattern).

## Spec slice
1. **BE (Flyway V4, DB fulfillment)**: `service_employees` (employeeCode, titleCode, paymentAccount, isActive), `service_employee_regions` (employeeCode → province/ward list), master regions/wards (từ seed regions + mở rộng tĩnh).
2. **API**: CRUD định nghĩa + `PUT active toggle` + `POST payment-account/verify` — **Zalopay API thật** qua env `ZALOPAY_*`; KHÔNG có credential → nhập tay + trạng thái "chưa xác minh" (CẤM giả lập kết quả verify).
3. **FE list**: lọc theo chức danh/NV/vùng; expand row xem danh sách phường/xã; toggle active; nút tạo (route riêng).
4. **FE define/edit**: chọn vùng (multi) → chức danh → NV (picker) → payment account (verify inline) → khu vực phụ trách theo tỉnh/phường (cây chọn, giới hạn dung lượng chọn — message khi vượt).
5. **Roles**: chỉ Admin tạo/sửa/toggle; role khác được xem list. Nav guard theo matrix mở rộng.
6. Design system SF-6; E2E spec mới; không đụng screens cũ (nav thêm item).

## ACCEPTANCE (user-visible)
- Admin tạo định nghĩa khu vực (2 vùng, 1 NV, payment verify xanh) → list hiện, expand thấy wards.
- Toggle active off → definition mờ/đánh dấu ngừng.
- Non-Admin không thấy nút tạo/sửa; gọi API → 403.
- E2E cũ + mới xanh.

## Boundary (KHÔNG làm)
- KHÔNG tích hợp HR hệ thống thật — employees nhập trong app; Zalopay verify THẬT khi có credential, không có thì manual.
- KHÔNG gán tự động khu vực vào đơn (mapping dùng về sau).
- KHÔNG đụng D1/D2 có sẵn.
