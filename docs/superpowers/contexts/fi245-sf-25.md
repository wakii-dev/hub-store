# FI-245 SF-25 Context Pack — KTV/CTV mobile web app
> Epic spec: docs/superpowers/specs/ict-service-support-postgres-prod-spec.md §3.25. Bracket: docs/superpowers/brackets/fi245-postgres-production.md. Tier 5 — deps SF-20 (tech FE + API) + SF-23 (PWA infra).

## Spec slice
1. **Mobile web app** (installable PWA — reuse SW/manifest pattern SF-23) cho KTV/CTV: breakpoint điện thoại (~375px), bottom-nav đơn giản.
2. **My orders hôm nay**: danh sách đơn giao + lắp đặt của KTV đang login (filter theo technician code), trạng thái rõ.
3. **Thao tác** theo buttons flags BE (SF-19): accept / complete / reschedule — reschedule chọn thời gian mới + ghi chú; complete ghi nhận giờ hoàn tất.
4. **Chi tiết đơn**: timeline, địa chỉ + deep-link mở map (SF-24 map component), gọi KH `tel:`.
5. **Auth**: cùng OIDC realm; role KTV/CTV (thêm roles `InsideTechnician`/`OutsideTechnician` vào realm JSON — password literal dev-only như users mẫu).
6. Design system SF-6 (tokens mobile); E2E spec mobile viewport.

## ACCEPTANCE (user-visible)
- Điện thoại mở app → login KTV → thấy đúng đơn hôm nay của mình.
- Accept → đơn chuyển trạng thái; complete ghi giờ; reschedule đổi thời gian + note.
- Bấm địa chỉ → mở bản đồ; bấm SĐT → dialer.
- Cài được lên màn hình chính (PWA).
