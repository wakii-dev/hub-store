# FI-245 SF-10 Context Pack — Realtime SSE
> Epic spec: docs/superpowers/specs/ict-service-support-postgres-prod-spec.md §3.10. Bracket: docs/superpowers/brackets/fi245-postgres-production.md. Tier 2 — deps SF-2 + SF-3 Done.

## Spec slice
1. BFF SSE endpoint (`GET /events` — EventSource stream): auth bằng access token (EventSource không set header được → query param `?access_token=` hoặc cookie — chọn 1, verify JWKS như API thường).
2. Event bus trong BFF: mutation đi qua BFF (REST routes) → publish event `{type, payload, ts}`: order.assigned / order.cancelled / order.completed / batch.created / batch.transitioned. Mutations chạy trực tiếp gRPC services (không qua BFF) → BFF subscribe qua gRPC server-streaming MỚI hoặc publish từ services → CHỌN KIẾN TRÚC ĐƠN GIẢN NHẤT KHÔNG ĐỔI PROTO CŨ (thêm streaming RPC mới nếu cần, hoặc services publish Postgres NOTIFY + BFF LISTEN — đề xuất NOTIFY/LISTEN vì cả 2 services đã trên Postgres, không đổi proto).
3. FE: hook `useRealtimeEvents` — subscribe, D1 orders table + D2 fulfillment refetch (RTKQ invalidates) khi event relevant; không optimistic-update phức tạp (refetch là đủ).
4. Reconnect tự động (EventSource native) + fallback polling 30s nếu SSE fail liên tục.
5. E2E spec mới: mutate ở context A → context B thấy update (2 pages cùng lúc).

## ACCEPTANCE (user-visible)
- 2 tab mở (2 user hoặc cùng user): tab A gán shop/complete đơn → tab B thấy row đổi trong ~1-2s, không F5.
- Giữ tab idle 5 phút → vẫn nhận event (reconnect hoạt động).
- SSE chết (kill BFF tạm) → FE fallback polling, không crash.
