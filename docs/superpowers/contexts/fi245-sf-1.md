# FI-245 SF-1 Context Pack — Postgres infra + seed pipeline
> Đọc file này THAY VÌ tự tổng hợp. Epic spec: docs/superpowers/specs/ict-service-support-postgres-prod-spec.md. Bracket: docs/superpowers/brackets/fi245-postgres-production.md.

## Spec slice (SF-1 chịu trách nhiệm)
1. `docker-compose.yml` thêm service `postgres`: image pin version, volume persistent, healthcheck `pg_isready`. **2 databases** (`fulfillment`, `batching`) tạo bằng init script mount `/docker-entrypoint-initdb.d/` (image chỉ tự tạo 1 DB qua `POSTGRES_DB` — verify behavior trước khi code).
2. **Env wiring cho app services (chủ quyền SF-1)**: thêm `environment:` blocks vào fulfillment-service / batching-service / bff với contract var TƯỜNG MINH: `FULFILLMENT_DB_HOST/PORT/NAME/USER/PASSWORD` (host `postgres`, port 5432, db `fulfillment`), `BATCHING_DB_*` (db `batching`), `OIDC_ISSUER=http://localhost:8081` + `OIDC_AUDIENCE=hubstore-api` + `OIDC_JWKS_URL=http://keycloak:8081` (issuer public khớp claim `iss` + browser; JWKS internal URL cho bff fetch trong network compose — 2 URL riêng, gotcha chuẩn Keycloak-in-Docker). Keycloak port của SF-4 — lấy giá trị từ đây, KHÔNG SF-4 sửa compose. Depends_on cũ `batching → fulfillment-service` GỠ (SF-3 boot độc lập).
3. **Compose cleanup seed remnant**: gỡ `SEED_PATH` / `CANONICAL_SEED_PATH` env + seed volume mount trên fulfillment/batching/print (chết khi chuyển DB — Go bỏ LoadSeedFile, Java seed-verify khác path).
4. `depends_on` đúng: db-seed `depends_on: orders-migrate + batches-migrate (service_completed_successfully)`; migrate one-shot → postgres healthy; app services → `db-seed: condition: service_completed_successfully` (KHÔNG chỉ service_healthy — tránh app boot trên DB rỗng, R3 vỡ setval).
5. **Seed pipeline CHỦNG QUYỀN cho cả 2 DB** (deliverable — script + standalone flow; full-chain compose verify là SF-5 vì bảng do migration SF-2/SF-3 tạo, chưa tồn tại ở tier 0): 1 script đọc `api/seed/canonical-seed.json` (GIỮ NGUYÊN) → nạp DB `fulfillment` (orders, shop_assignment_history, regions, delivery_staff — theo SeedModels) và DB `batching` (batches, batch_items — theo seed struct Go). Script phải **fail với message rõ khi bảng chưa tồn tại** ("chạy migration trước — see SF-2/SF-3").
6. Idempotent theo **emptiness-gate**: DB rỗng → nạp; có data → KHÔNG đụng. KHÔNG upsert. Seed file đổi sau này = reset thủ công (ghi README ngắn).
7. Check `orderCode` của batch items tồn tại trong DB `fulfillment.orders` khi nạp batches — item lạ → FAIL pipeline message rõ.
8. `db-seed` + 2 one-shot **migrate services** (`orders-migrate` flyway CLI, `batches-migrate` golang-migrate CLI trỏ migration dirs của SF-2/SF-3) — WIRED trong compose từ SF-1 (config-level; test full-chain là SF-5) + script standalone `bash scripts/seed-db.sh` cho dev flow.
9. Reset util `scripts/reset-db.sh`: `TRUNCATE ... RESTART IDENTITY` cả 2 DB + reseed + **setval batch sequence = max batchCode seed**; ĐỒNG THỜI xóa keycloak volume (SF-4 realm re-import sạch). Boot-all gọi khi `E2E=1` (wire là SF-5).
10. `.env.example` mới: mọi biến hiện có + POSTGRES_* + FULFILLMENT_DB_* + BATCHING_DB_* + OIDC_ISSUER/AUDIENCE + KEYCLOAK_*; compose pattern `${POSTGRES_PASSWORD:?}`; KHÔNG thêm secret mới vào git-tracked `.env` (dev default local-only ghi rõ README).
11. `scripts/wait-db.sh` dùng chung (Java run.sh SF-2, Go run.sh SF-3, boot-all SF-5 gọi — tránh 3 bản copy).
12. Compose thêm service block `keycloak` (image pin, port 8081, realm-import mount `docker/keycloak/` — CHỪA dir + mount; realm JSON nội dung là SF-4, password trong realm JSON là **literal dev-only — KHÔNG env-substitution**).

## ACCEPTANCE (user-visible — tier-0 scope)
- `docker compose up -d postgres` → healthy; initdb tạo đúng 2 DB (`psql -l` thấy fulfillment + batching).
- `docker compose config` hợp lệ với các service mới (migrate/db-seed/keycloak + env wiring + depends_on chain).
- `bash scripts/seed-db.sh` trên DB có sẵn bảng (tạo tay test) → nạp đúng; chạy lại → không đổi (emptiness-gate); trên DB CHƯA có bảng → fail message rõ.
- `bash scripts/reset-db.sh` → truncate + setval đúng (test trên bảng tay).
- Gỡ SEED_PATH/CANONICAL_SEED_PATH/depends_on cũ khỏi compose — không còn reference chết.
