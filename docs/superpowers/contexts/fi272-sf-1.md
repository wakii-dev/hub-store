## Spec slice (SF-1 chịu trách nhiệm)

1. Tạo `k8s/base/` + `k8s/overlays/minikube/` skeleton. **Composition contract (P0 plan-critic):**
   `k8s/base/kustomization.yaml` viết MỘT LẦN bởi SF-1, pre-include TẤT CẢ component dirs:
   `postgres/`, `keycloak/`, `apps/fulfillment/`, `apps/batching/`, `apps/print/`, `apps/bff/`, `apps/web/`
   — mỗi dir có placeholder `kustomization.yaml` (namespace-only). SF-3/SF-4 sau này CHỈ thay nội dung
   dir của mình, KHÔNG BAO GIỞ sửa base kustomization → tier-1 chạy song song không same-file conflict.
2. Namespace `hub-store` (kustomize namespace transformer).
3. Secrets dev-only (ghi rõ comment dev-only, KHÔNG secret thật): `postgres-credentials`
   (user/pass/db), `jwt-dev-secret` (khớp JWT_DEV_SECRET BFF đọc — services/bff-gateway/src/config.ts
   fail-loud nếu thiếu), `keycloak-admin`.
4. Seed ConfigMap qua `configMapGenerator` từ `api/seed/canonical-seed.json` (48KB — dưới 1MB limit;
   thêm comment cảnh báo khi file phình ~800KB phải đổi cơ chế).
5. Postgres StatefulSet `postgres:16` — PVC (RWO, đủ cho dev), initdb script tạo 3 DB:
   `fulfillment`, `batching`, `keycloak` (mount docker-entrypoint-initdb.d); liveness/readiness bằng
   `pg_isready`; Service ClusterIP `postgres:5432`.
6. **Kafka KRaft single-broker StatefulSet** (WIRING SLOT — user chốt 2026-09-02): StatefulSet
   `kafka-0`, KRaft mode KHÔNG ZooKeeper. **Image: chốt ở Phase 3 plan của SF-1** — mặc định
   apache/kafka (env KAFKA_NODE_ID/KAFKA_CLUSTER_ID/listeners theo convention image đó); nếu
   chọn bitnami/kafka phải map lại surface KAFKA_CFG_*. Pin tag + ghi rationale (không đòi
   "ổn định"). PVC, health (kafka-broker-api-versions hoặc liveness exec theo image).
   **Advertised-listener contract (P1):** advertised.listeners của client-facing listener PHẢI
   resolve được `kafka:9092` Service DNS từ trong cluster — nếu không, SF-1 gate vẫn pass nhưng
   SF-5 round-trip sẽ fail (lỗi single-broker-on-k8s kinh điển — verify sớm bằng kafka-broker-api-versions
   qua Service DNS chứ không phải pod DNS).
   **Heap/resources (P1):** KAFKA_HEAP_OPTS cap (vd -Xmx1g -Xms512m) + requests/limits bắt buộc.
   Service `kafka:9092` (client) + headless service cho StatefulSet.
   **Topic CONTRACT `orders.events`** (bootstrap job/initContainer chạy kafka-topics --create
   --if-not-exists) — tên này là contract cross-SF với SF-5, KHÔNG TỰ ĐỔI; đổi chỉ bằng quyết
   định epic-level. **App services KHÔNG produce/consume** — chỉ provision. HA out-of-scope
   (minikube dev — ghi rõ docs). Verify broker healthy TRƯỚC khi qua task khác.
7. `scripts/k8s-build-images.sh` — **ENTRY POINT DUY NHẤT cho build image** (SF-4 sẽ call; SF-2
   KHÔNG có build riêng): `minikube image build -f <dockerfile> -t hub-store/<name>:<tag> .` ×5
   (fulfillment-service, batching-service, print-service, bff-gateway từ services/*/Dockerfile,
   web từ Dockerfile.web) — TẤT CẢ build context = repo root (đã verify). Tag mặc định `dev`,
   overridable bằng env.
8. Preflight script (vd `scripts/k8s-preflight.sh`): detect minikube installed (thiếu → FAIL-LOUD +
   hướng dẫn cài), detect driver (docker/orbstack/hyperkit/…), check resource đủ (khuyến nghị
   `minikube start --memory=6g --cpus=4` — stack có Java + Keycloak + Kafka dễ OOM trên default 2GB);
   check addons ingress. Idempotent, exit non-zero khi thiếu.
9. README section "K8s / minikube deploy — requirements + preflight" — SF-1 KHÔNG đụng phần khác
   của README (deploy guide là SF-5).

## ACCEPTANCE (user-visible)

- `bash scripts/k8s-preflight.sh` trên máy có minikube → báo driver + resource + addon, thoát 0;
  thiếu minikube → thông báo rõ + thoát non-zero.
- `bash scripts/k8s-build-images.sh` → 5 images `hub-store/*:dev` trong `minikube image ls`.
- Apply riêng SF-1 (apply -k overlay minikube) → pod postgres Running healthy, `psql` thấy 3 DB
  fulfillment/batching/keycloak; pod sống qua rollout restart (PVC mount).
- Pod kafka-0 Running healthy; topic `orders.events` tồn tại (kafka-topics --list qua kubectl run);
  metadata broker trả về qua Service DNS `kafka:9092` resolvable (advertised listener đúng).
- `kubectl apply -k k8s/base` build không lỗi với placeholder dirs (composition contract hoạt động).
