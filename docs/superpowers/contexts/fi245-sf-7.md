> Epic spec: docs/superpowers/specs/ict-service-support-postgres-prod-spec.md §3.7. Bracket: docs/superpowers/brackets/fi245-postgres-production.md. Tier 2 — deps SF-2 Done.

## Spec slice
1. Bảng `activity_log` (DB `fulfillment`, Flyway migration V2 — SF-2 owns schema dir nhưng SF-7 THÊM file migration mới, không sửa V1): actor (username), action, targetType, targetId, detail JSONB, createdAt.
2. Ghi audit tại MỌI mutation endpoint của orders: assignShopHub, cancel, complete, batch create/transition (ghi qua Java service nơi mutation chạy — batch mutations qua gRPC response ở BFF cũng log được qua BFF plugin nếu dễ hơn; chọn 1 chỗ nhất quán).
3. Audit query API: GET list có filter (actor/action/date range) — phục vụ SF-11 viewer.
4. Export CSV endpoint: cùng filter params như list orders; stream response; content-type text/csv; tên file có timestamp.
5. Pagination server-side: `page`/`pageSize` + trả `{items, total, page, pageSize}` — DÙNG window function như SF-2 đã có (COUNT OVER). Batches list tương tự qua Go (deps SF-3 dùng PostgresStore List — mở rộng cursor/offset giữ sort semantics).
6. Legacy compat: response shape hiện tại KHÔNG vỡ — thêm envelope mới hoặc query param opt-in; E2E specs cũ phải xanh KHÔNG sửa.
