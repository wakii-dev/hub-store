# FI-245 SF-23 Context Pack — PWA + Push OneSignal + GA
> Epic spec: docs/superpowers/specs/ict-service-support-postgres-prod-spec.md §3.23. Bracket: docs/superpowers/brackets/fi245-postgres-production.md. Tier 4 — deps SF-10 Done (event nguồn push).

## Spec slice
1. **PWA**: manifest (name, icons, theme color #EB6E09) + service worker (precache shell, runtime cache tĩnh, offline fallback trang tĩnh "mất mạng"); installable (Chrome/Edge/Safari iOS).
2. **OneSignal**: init qua env `VITE_ONESIGNAL_APP_ID` (env trống → feature off, không lỗi); subscribe khi user login; push events từ BFF khi: đơn mới vào (SF-13/webhook), batch hoàn tất, vận đơn đổi trạng thái quan trọng — server key qua env BFF `ONESIGNAL_REST_API_KEY` + external user mapping theo username.
3. **GA**: hook qua env `VITE_GA_MEASUREMENT_ID` (trống → off) — pageview route + sự kiện nghiệp vụ chính (tạo đơn, tạo phiếu, hoàn tất, in).
4. Tất cả credential/id qua env — .env.example cập nhật; KHÔNG hardcode; KHÔNG thêm secret mới vào git.
5. E2E: PWA manifest + SW đăng ký kiểm được; push/GA chỉ smoke-check off-mode (env trống) để E2E ổn định.

## ACCEPTANCE (user-visible)
- Mở app → browser hiện nút cài (installable); offline → fallback trang tĩnh đẹp.
- Login → nhận push thật khi có đơn mới (cần credential từ user).
- Env trống → app chạy bình thường, không console lỗi.
- E2E xanh.

## Boundary (KHÔNG làm)
- KHÔNG offline mode đầy đủ (CRUD offline queue — sau).
- KHÔNG push preference center phức tạp — on/off theo login.
- KHÔNG analytics tracking user cá nhân (chỉ events ẩn danh chuẩn GA4).
