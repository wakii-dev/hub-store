1. **DESIGN-FIRST bắt buộc (gate user)**: trước khi code bất cứ điều gì — tạo 3 hướng HTML prototype (shell + D1 orders sample, đủ breadth để lộ design system) → user CHỌN 1 hướng (bắt buộc, không bỏ qua) → hand-off file `docs/superpowers/designs/sf6-direction.md` (theme tokens + structure rules + behavior notes) → MỚI code theo direction đã duyệt.

3. **Theme**: LESS tokens mới trên antd4 — palette mở rộng từ #EB6E09, radius, shadow/depth, spacing scale, typography; skeletons + empty-states; micro-interactions (hover/transition); polish màn login wrapper.
4. **Cứng (vi phạm = fail)**:
   - KHÔNG nâng antd5 — vẫn antd4 + LESS.
   - KHÔNG đổi testids hay cấu trúc DOM mà E2E Playwright phụ thuộc (13 specs phải xanh KHÔNG sửa assertions).
   - KHÔNG đổi business logic, API calls, state management.
   - KHÔNG đụng e2e/, services/, docker-compose (SF-5 read-only apps/** — tương tự SF-6 KHÔNG đụng infra của SF-5).
