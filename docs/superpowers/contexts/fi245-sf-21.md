# FI-245 SF-21 Context Pack — Print expansion + platform polish
> Epic spec: docs/superpowers/specs/ict-service-support-postgres-prod-spec.md §3.21. Bracket: docs/superpowers/brackets/fi245-postgres-production.md. Tier 4 — deps SF-15 (booking data cho handover docs) + SF-6 (design system).

## Spec slice
1. **5 loại chứng từ**: bill (biên nhận), delivery (vận đơn), handover_receipt (giao nhận NVC), goods_handover (bàn giao hàng), installation_acceptance (biên bản lắp đặt) — mở rộng D3 print hiện có (KHÔNG thay, THÊM types).
2. **Printer management**: bảng `printers` (DB, Flyway V7 hoặc trong fulfillment schema) — printerIp/mac/type (bill vs A4)/shop; FE chọn máy in theo shop trong màn print; CRUD nhẹ (list + thêm/sửa — Admin).
3. **Print errors per-đơn per-type**: record lỗi khi in fail; sort đơn nhiều lỗi nhất lên đầu; badge hiển thị.
4. **Preview**: PDF/ảnh preview + zoom 25–200% (nâng cấp preview hiện có nếu có — additive).
5. **"In tất cả"** = mọi printType cho các đơn checked; chỉ cho phép đơn status hợp lệ.
6. **Platform polish**: hotkeys toàn cục (F4 save, F6 create, F8 cancel — helper dùng chung + đăng ký tại form chính); empty-states component dùng chung; áp vào screens mới của story.
7. **Platform polish từ app gốc** (coverage gap-check 2026-09-02): avatar upload (crop client-side, JPG/PNG <5MB, persist — BFF endpoint lưu file/DB nhẹ); font-size slider trong header (12–20px, persist localStorage, áp theme); hotkey helper modal (bảng phím tắt + ô search); fullscreen toggle (F11 + nút header); version badge + check-version (fetch version, prompt reload khi mới).
8. KHÔNG đổi testid/DOM mà E2E cũ phụ thuộc; E2E print cũ (nếu có) phải xanh; E2E spec mới cho types mới.

## ACCEPTANCE (user-visible)
- Chọn đơn → in được cả 5 loại; preview từng loại với zoom.
- Chọn máy in bill vs A4 → layout đúng; thêm máy in mới → chọn được.
- In fail (máy off) → lỗi ghi nhận, màn print sort đơn lỗi lên đầu.
- F4/F6/F8 hoạt động tại form tương ứng; screens mới có empty-state đẹp.
- Upload avatar (crop) → header hiện avatar mới sau reload; font-size slider đổi cỡ chữ toàn app và giữ sau reload; F11 fullscreen; hotkey helper mở được.
- E2E cũ + mới xanh.
