## Spec slice
1. **Schema (Flyway V6, DB fulfillment)**: `delivery_orders` (code, status — 10 mã giao, driver, receiver/sender tên+SĐT+**lat/long**, phí, khuyến khích, items JSONB, region, province, coordination, createdAt), `installation_orders` (serviceOrderCode, technician, expectedTime, timeline JSONB, liên quan deliveryOrderCode, serviceFee payout/adjust), `technicians` (code, tên, loại KTV/CTV, vùng).
2. **API**: list delivery + list installation (filter: trạng thái, NV, ngành hàng L1/L2, vùng, tỉnh, khoảng ngày); assign/re-assign technician; **suggest employee** (theo vùng + workload đơn giản); timelines đọc.
3. **Buttons BE-authoritative** per record: allowCancel/Assign/Accept/Reschedule/Reassign — FE render theo flag (không tự suy).
4. Seed mẫu: file seed riêng (KHÔNG đụng canonical-seed.json).
5. Unit + API tests; pagination SF-7.
