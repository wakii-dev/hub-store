# FI-245 SF-3 Context Pack — Batches Go → Postgres
> Đọc file này THAY VÌ tự tổng hợp. Epic spec: docs/superpowers/specs/ict-service-support-postgres-prod-spec.md. Bracket: docs/superpowers/brackets/fi245-postgres-production.md.

## Spec slice (SF-3 chịu trách nhiệm)
1. **golang-migrate batches schema V1** (trong `services/batching-service/migrations/`): bảng `batches` (batchCode PK, shopCode, shipperId, deliveryTime, status, createdAt), `batch_items` (batchCode FK, stopOrder, orderCode, customerAddress, distance, fromDeliveryTime, toDeliveryTime, orderStatus, orderType, items JSONB/fields, totalQuantity, codAmount). Pin golang-migrate version.
2. **`BatchStore` interface (mới)** + `PostgresStore` impl bằng **pgx v5** (pin version; go.mod chỉ thêm pgx + migrate lib):
   - `Transition` CAS → `UPDATE batches SET status=$to WHERE batch_code=$code AND status=$from`; rowsAffected=0 → trả lỗi CAS như hiện tại.
   - `CreateWithNextCode` / `NextBatchCode` → Postgres **sequence** atomic; format `BATCH-%04d` giữ nguyên; sequence `setval` = max batchCode seed (do SF-1 reset util lo khi reset; SF-3 đảm bảo migrate/init setval lúc bootstrap nếu trống).
   - `List`: giữ sort semantics (createdAt → batchCode) — ORDER BY tường minh.
   - `Get/Put/Delete` (Delete = compensation path của CreateBatch — giữ).
   - Hydration payload shape không đổi (gRPC `Batch` message nguyên vẹn).
3. **BỎ `LoadSeedFile`** + seed struct đọc JSON: data batches do seed pipeline SF-1 nạp sẵn vào DB. Go chỉ migrate schema rồi đọc DB. Boot KHÔNG phụ thuộc Java (hydration chỉ khi serve request — như hiện tại, client deadline).
4. `migrate-entrypoint`: Dockerfile/entrypoint — wait-for-db → golang-migrate up → serve. gRPC server bootstrap đọc env DB thay vì `CANONICAL_SEED_PATH`.
5. Unit tests: store tests chuyển sang interface + PostgresStore (skip-if-no-DB) + giữ test logic CAS/next-code qua integration.

## ACCEPTANCE (user-visible)
- Standalone flow: `docker compose up -d postgres batches-migrate` (wiring SF-1) + `bash scripts/seed-db.sh` → `psql` DB batching thấy BATCH-0001 + batch_items.
- Go service lên với Postgres (không cần Java đang chạy): list batches trả seed data (BATCH-0001 ACTIVE…).
- CreateBatch → batch mới lưu DB, code tiếp dải seed (bootstrap setval max-seed khi sequence trống); Cancel/Complete → status persist qua restart.
- 2 request CreateBatch đồng thời → 2 code khác nhau (sequence atomic, không trùng).
- `go test ./...` pass (integration skip khi không có DB).
