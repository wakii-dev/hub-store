## Spec slice
1. **BE (Flyway V5, DB fulfillment)**: `d2c_orders` (orderCode, orderIdInter, deliveryId, carrier, shop, exportEmployee/exportTime, pushTime, receiver info, serviceType, isDebtSplitting, note, status, createdAt).
2. **API**: filter đa chiều (orderCode/deliveryId, status, carrier, shop D2C, NV xuất, ngành hàng, loại SP, khoảng ngày tạo, khoảng/khung giờ đẩy — khớp bộ lọc gốc) + pagination SF-7 + note update.
3. **Export Excel/CSV**: ≤31 ngày (validate, lỗi message rõ); file `D2C_Order_{from}_{to}`; pattern SF-7 stream.
4. **FE**: list + bảng + expand (push/export info, người nhận, service type, tách nợ, ghi chú); bộ lọc đầy đủ; note modal; nút export với date-range guard.
5. **Roles**: WarehouseEmployee + 87333-role tương đương (dùng role có sẵn — nếu thiếu, thêm role vào realm qua REQUIREMENT-GAP); perm List/Export/Update.
6. Design system SF-6; E2E spec mới; dữ liệu D2C seed mẫu nhỏ (file seed D2C riêng — KHÔNG đụng canonical-seed.json).
